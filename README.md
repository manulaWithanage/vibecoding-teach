# ⚡ Vibe Coding — Lesson 1: Foundations & Interactive Project

An interactive, responsive, friendly teaching website for learning **Vibe Coding** with **Google Antigravity**. Designed for pairs, study groups, and friends getting started with AI-assisted software creation.

---

## 📚 What's Inside Lesson 1

1. **What is Vibe Coding?** — The mindset shift from typing every line to architecting with AI agents.
2. **Download & Setup Antigravity** — Download the visual **Antigravity IDE** (desktop app) or install **Antigravity 2.0 CLI** (`agy`).
3. **Model Guide & Shortcuts** — Understanding which model is best for what:
   - ⚡ **Gemini 3.8 Flash** (`High Priority` • Default) — Sub-second UI iterations, CSS styling, rapid bug fixing.
   - 🧠 **Gemini 4 Argon** (`Medium` • `New`) — Deep multimodal reasoning, system planning, analyzing reference image screenshots.
   - 🎨 **Claude Sonnet 5.5** (`Medium` • `New`) — Premier front-end aesthetics, typography, and micro-interactions.
   - 🏗️ **Claude Opus 5.5** (`Medium` • `New`) — Heavyweight multi-file codebase architecture and database schemas.
   - 🌐 **GPT-OSS 120B** (`Medium` • `Notice ⓘ`) — Open-weights powerhouse for private/local workflows.
   - ⌨️ Shortcut: Press `Ctrl + /` anywhere in Antigravity to toggle models instantly.
4. **The 3-Step PCE Formula** — Plan, Constrain, and Execute.
5. **Easy Bug Fixing** — The 3-step console error debug loop.
6. **Quick Knowledge Check** — Interactive audio-supported quiz.
7. **First Practical Test: Portfolio Hero Section** — Live sandbox builder with:
   - Avatar selection (preset & custom URLs)
   - 4 Live visual polish styles (Glow Aura, Glassmorphism, Cyber Neon, Clean Minimal)
   - Step-by-step practical guide to reviewing first drafts and prompting iterative UI refinements
   - **📸 Reference Images**: How to take screenshots of design inspiration and drop them into Antigravity for automated styling matching.
