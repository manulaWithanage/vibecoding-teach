    Lesson 1: Introduction to Vibe Coding 👋

    Welcome! In this lesson, you'll learn how to build real software by directing AI agents in plain English. No syntax memorization. Just clear ideas, quick feedback, and fast building.

    1. What is Vibe Coding?

    Mindset

    Traditional coding meant typing every bracket and semicolon manually. Vibe coding turns you into the Product Architect: you describe what you want, review the result, and ask for tweaks.

    ⌨️ Traditional Way

    Memorizing syntax rules, reading documentation manuals, and fighting syntax typos for hours.

    🚀 The Vibe Way

    Express your ideas in natural language. The autonomous agent writes the code and installs the assets.

    👑 Your Job

    Focus on UX, aesthetics, features, and testing the live app in your browser.

    Set Up Your Project Folder First

    Before you prompt anything, give your project its own folder. Create it from the terminal, or make it normally in Explorer / Finder — then open that folder in Antigravity.

    1. Create & name your project folder:
    mkdir my-portfolio
    2. Move into that folder:
    cd my-portfolio
    3. Open it in Antigravity:
    File → Open Folder → my-portfolio

    📂 Name It Properly

    Use lowercase letters and hyphens — my-portfolio, coffee-shop-site. No spaces, no capitals, no New Folder (2). The agent reads your folder name as context, so a clear name gives you better code from the very first prompt.

    4. The 3-Step PCE Formula

    Prompting Secret

    Never ask AI to build an entire massive application in one prompt. Use the PCE Framework:

    P

    Plan First

    Ask for a clear outline before generating any code.

    C

    Constrain

    Set clear tech limits: "Single-file HTML with Tailwind CSS and an avatar photo."

    E

    Execute

    Instruct the AI to build one section at a time.

    PCE MASTER PROMPT TEMPLATE 
    "Act as a Senior Frontend Developer.
1. Outline the structure to build a clean portfolio hero section before writing code.
2. Constraints: Single index.html file, Tailwind CSS via CDN, and a placeholder profile image.
3. Build Step 1: the semantic HTML layout with header and call-to-action buttons."

    5. Easy Bug Fixing (The Debug Loop)

    No Stress

    Encountered a red error in your browser console? Don't spend hours searching forums. Use the 3-step debug loop:

    1. Copy Error

    Open Developer Tools (F12) and copy the red error message.

    2. Paste to AI

    Type: "Fix this error while keeping existing styles: [paste error]".

    3. Test & Enjoy

    Refresh your browser. The AI fixes the code automatically.

    How to Polish Your UI with AI (The Real Workflow)

    In actual vibe coding, you don't stop at v1 — you guide the AI with feedback & reference images!

    👀 Step 1: Inspect Your First Draft in the Browser

    When you run your initial prompt in Antigravity, the AI produces a functional first draft. Open it in your browser and check:

    • Spacing & Padding: Does the layout feel cramped? Give elements room to breathe.
    • Typography Contrast: Is the headline bold and readable against the background?
    • Hover & Micro-interactions: Do buttons respond when hovered, or do they feel flat?

    💬 Step 2: Prompt Specific Micro-Refinements

    Instead of generic prompts, ask for specific design upgrades. Click any prompt chip below to copy it:

    🔮 Glow Aura "Add a glowing radial backdrop aura behind the avatar..."
    📋
    🪟 Glassmorphism "Convert the hero container to frosted glass with blur..."
    📋
    ✨ Button Lift & Glow "Make CTA button have rounded pill shape & hover scale..."
    📋
    📱 Mobile Responsive "Ensure layout collapses cleanly on mobile screens..."
    📋
    📸

    Pro Tip: Use Reference Images! (The Vibe Coder Secret)

    Found a website, Dribbble shot, or portfolio on Twitter with an aesthetic you love? Take a screenshot (Win+Shift+S or Cmd+Shift+4) and drag & drop it directly into your Antigravity chat!

    Multimodal models like Gemini 4 Argon and Claude Sonnet 5.5 can inspect the screenshot, extract colors, typography, and spacing, and reproduce the look in your project.

    💡 Click to copy: "Match the layout, spacing, and color palette of this reference screenshot..." 📋
